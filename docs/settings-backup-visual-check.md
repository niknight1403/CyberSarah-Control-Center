# Mobile Visual QA: Settings-Backup

Datum: 2026-08-26

Die mobile Settings-Ansicht wurde auf einem schmalen Portrait-Viewport geprüft. Die bestehende Void-Dark-Struktur, Safe-Area, Eingabefelder und die neue Backup-Sektion rendern ohne sichtbaren Layout- oder Bundle-Fehler. Der Exportbereich liegt unterhalb der Datenschutz- und Endpoint-Konfiguration und verwendet ein eigenes Passwortfeld, eine Sicherheitszusammenfassung sowie einen klaren primären Teilen-Button. Der Web-Preview zeigt erwartungsgemäß die native-only Einschränkung für SecureStore-/Share-Funktionen; der eigentliche verschlüsselte Export ist für Android/iOS vorgesehen.
